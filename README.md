# 免费异动助手 v0.8（独立免费 Android 版）

本仓库用于构建独立 Android APK。行情由手机端直接请求腾讯、新浪和东方财富公开接口，不要求用户购买域名、租服务器或配置后端。

## 功能
- 自选行情：腾讯公开行情，失败时尝试新浪公开行情。
- 全市场观察榜：东方财富公开行情快照，按涨跌幅绝对值筛选。
- 10/30 日偏离估算：东方财富历史日线及参考指数。
- 次日涨跌停参考价：按常见板块规则估算。
- 自选股和设置保存在本机。
- 无登录、会员、订阅或内购。

## 自动构建 APK
1. 打开仓库的 Actions 页面。
2. 选择 Build Android APK，点击 Run workflow；推送到 main 的代码更新也会自动触发构建。
3. 等待任务完成，进入该次运行记录。
4. 在页面底部 Artifacts 下载 free-abnormal-assistant-debug-apk。
5. 解压 ZIP，安装其中的 app-debug.apk。首次安装可能需要允许浏览器或文件管理器安装未知来源应用。

## 重要限制
- 行情接口是第三方免费公开接口，可能限流、改版、延迟或拒绝请求；不保证持续可用。
- 当前没有后台常驻监控或可靠推送；提醒仅在应用运行、行情刷新时触发。
- 10/30 日偏离和涨跌停价是辅助估算，不是交易所官方认定或投资建议。新股上市初期、特殊复牌、除权除息、ST 状态等需人工核实。
- 工作流生成 debug APK，未做正式发布签名；请仅从自己控制的仓库下载构建产物。
